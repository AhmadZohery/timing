# OPP-0103: Dynamic CEFR Custom Deck & CSV/JSON Importer

## 1. Problem Statement
The current vocabulary module is hardcoded to a static array of ~1,200 words in `src/data/languages/vocabularyDatabase.ts`. Intermediate and advanced learners studying specialized topics (e.g. medical, legal, colloquial dialects) cannot add their own terms or import existing Anki flashcard collections.

## 2. Evidence Base
- `src/services/spacedRepetitionService.ts` contains a fully functional SM-2 spaced repetition scheduler.
- Dexie schema already includes `vocabularyWords` and `vocabularyProgress` tables.
- Hardcoded static data limits user retention and long-term utility.

## 3. Counter-Evidence & Risks
- Malformed CSV/JSON uploads could corrupt client database state or inject malicious script tags if not sanitized.
- Potential performance slowdown if a user imports 10,000+ words into IndexedDB at once.

## 4. Alternatives Considered
- **Alternative A:** Client-side CSV/JSON parser with batch Dexie bulkAdd (chunks of 200 items), schema validation via Zod, and DOMPurify sanitization.
- **Alternative B:** Simple manual one-by-one card creation modal. (Insufficient for serious language learners).

## 5. Technical Architecture
1. Add `CustomDeckModal.tsx` allowing drag-and-drop CSV, JSON, and tab-delimited text.
2. Provide template generator (Term, Translation, Pronunciation, Example Sentence, CEFR Level).
3. Validate each row, sanitize strings, and insert into Dexie `customDecks` and `vocabularyWords`.
4. Export capability to standard Anki-compatible CSV format.

## 6. Success Metrics
- 100% parse success rate on standard CSV exports from Quizlet and Anki.
- Batch import of 1,000 cards completes in under 300ms.
